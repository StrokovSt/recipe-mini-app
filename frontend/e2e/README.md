# Скриншот-тесты мобилки

Каждый экран телефона (390×844) снимается в светлой и тёмной теме и сравнивается с эталоном из `__screenshots__`.
Если правка (например, для компьютера) задела телефон, тест упадёт и покажет, что изменилось.

## Первый запуск

```
npm install
npx playwright install chromium
npm run test:screens:update
```

Последняя команда снимает эталоны. Их стоит закоммитить: дальше с ними сверяется каждый запуск.

## Обычная проверка

```
npm run test:screens
```

Всё зелёное: телефон не изменился. Если тест упал, откройте отчёт `npx playwright show-report`:
там для каждого экрана эталон, новый снимок и разница, подсвеченная красным.

- Изменение случайное: чините код и запускайте снова.
- Изменение задумано (поменяли дизайн): `npm run test:screens:update` и коммит новых эталонов.

## Как устроено

- `screens.e2e.ts`: список экранов и действий (шторка фильтров, меню, история поиска, меню «⋯» рецепта, вкладка тегов, главная на узком экране 320px).
- `api.ts`: подмена ответов сервера. Бэкенд не нужен, данные всегда одни и те же, поэтому снимки не «плывут».
- Анимации выключены, тесты ждут, пока уйдёт заставка и загрузятся шрифты.
- Эталоны снимаются на одной машине: Windows и Linux рисуют шрифты чуть по-разному.
